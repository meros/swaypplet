## What it is
A CSS easing function taking a list of progress stops, optionally with positions: `linear(0, 0.25 75%, 1)`. The browser interpolates straight lines between them. Baseline across browsers since December 2023.

## What was new
Springs, bounces and any other curve can be expressed in CSS by sampling them into 20–60 stops, generated by tools from a spring's parameters. It closed the gap between JS spring libraries and declarative CSS without adding a physics engine to CSS.

## What went wrong / limits
It is a baked curve for a fixed duration: no velocity handoff, no retargeting. Long stop lists are unreadable.

## Lessons for swaypplet
- Adapt: GTK CSS has no `linear()`, but the idea applies: sample `anim.rs`'s curve (or a spring) into a table and use it on both sides, so Rust and CSS can never drift apart. Today they share only cubic-bezier.
