## What it is
A Quicksilver-inspired launcher for Linux in Python/GTK with a three-pane object, action, indirect-object model and Python plugins.

## What was new
- Brought Quicksilver's grammar to Linux with typed objects: a text, a file, a contact each get the actions that fit.
- "Proxy objects": the selection, the current window, the last result can be used as an object.

## What went wrong / limits
- Niche: the grammar asks for learning; the project passed between maintainers and stayed small.

## Lessons for swaypplet
- Take proxy objects: "selected text", "focused window", "last result" as rows the action list can act on.
