## What it is
A Java 3D desktop started by Sun engineer Hideya Kawahara in 2003, adopted by Sun and released under the GPL. Windows could be turned sideways into thin "spines" to save space, flipped to write notes on their backs, and arranged in a 3D panorama. Inactive from late 2006.

## What was new
Windows as objects with depth and a back side; spines as a compact parked state.

## What went wrong / limits
Required Java 3D and hardware few had; apps were ordinary 2D windows, so 3D added navigation without adding information. No path from demo to daily use; Sun's decline ended funding.

## Lessons for swaypplet
- Avoid: a spatial dimension that holds no information. The parked-window "spine" survives as a good idea for pins: a compact, still representation of something set aside.
