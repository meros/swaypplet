## What it is
GNOME 3.0 (April 2011) replaced GNOME 2's panels, menus and minimise buttons with GNOME Shell: one top bar, an Activities overview for windows, launching and workspaces, dynamic workspaces and few settings. Linus Torvalds called it an "unholy mess" and moved to Xfce; Linux Mint forked GNOME 3 into Cinnamon and others revived GNOME 2 as MATE.

## What was new
The overview as the single hub for switching, launching and searching; keyboard-first Super to search; dynamic workspaces. Much of this was later copied, and GNOME Shell is now the most used Linux desktop.

## What went wrong / limits
Removed customisation and familiar controls at once, with extensions as the only escape hatch, which then broke every release. Users with established workflows felt told they were wrong.

## Lessons for swaypplet
- Take: the Super-to-overview-and-type model works; it is the reference for the long-Super overview (roadmap item 4).
- Note: swaypplet has one user, so paradigm shifts cost less, but a change that removes a habit should arrive with its replacement, not before.
