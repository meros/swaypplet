## What it is
An OLED touch strip replacing the function keys on MacBook Pros from October 2016, showing controls that changed with the focused app. Dropped from the 14 and 16 inch models in 2021, gone from all Macs in October 2023.

## What was new
Context-sensitive controls in a fixed physical place.

## What went wrong / limits
It removed tactile function and Escape keys that developers and terminal users hit without looking. Controls changed under the user's fingers, so muscle memory could not form; accidental brushes triggered actions. Apple never extended it after launch and developer support faded.

## Lessons for swaypplet
- Avoid: a surface whose controls change with the focused app (the rejected per-app context segment); position must mean the same thing always (BAR_VISION P4).
- Take: never replace a blind-operable control with one that needs looking.
