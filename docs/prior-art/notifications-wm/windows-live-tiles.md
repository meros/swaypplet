## What it is
Animated tiles on the Windows Phone 7 (2010) home screen, then the Windows 8 Start screen and Windows 10 Start menu: each tile flipped between app icon and live content (new mail, headlines, photos). Windows 11 (2021) replaced them with a static icon grid and moved live content to Widgets.

## What was new
Launcher and dashboard in one surface: the icon you tap also tells you what changed.

## What went wrong / limits
On the desktop the Start menu is opened to launch something and closed in seconds, so live content was rarely read; tiles cost space. Constant flipping is motion at rest. Developers stopped updating tile content as the Store app ecosystem shrank. Windows Central argued tiles were not why Windows Phone failed; they were simply not useful on the PC.

## Lessons for swaypplet
- Avoid: live content in a launcher; a launcher is a transit surface.
- Take: a status glyph on a launcher item is fine if it only appears when it needs action and is static.
